# 指标与判断口径

先确认用户现有定义；以下为需要声明适用条件的默认分析口径。缺少字段就限制结论，不补造数据。

| 指标 | 口径及限制 |
| --- | --- |
| 有效订单 | 按约定统计已支付、排除测试/取消的订单；退款订单是否保留在订单数中必须说明 |
| 净收入 | 折后商品收入 + 运费收入 − 实际退款；默认不含代收税款。已折后金额不再扣折扣 |
| 客单价 | 与同一订单集合对应的收入 ÷ 订单数；注明是否扣退款、是否含运费 |
| 广告前贡献 | 净收入减商品、支付、包装、履约和其他变动成本；确认成本包含范围，避免重复 |
| 广告后贡献 | 广告前贡献减广告花费；不是自动扣完固定费用的净利润 |
| ROAS | 单平台归因收入 ÷ 该平台花费，说明窗口/币种/收入范围；不能相加为实际收入 |
| MER | 本期实际收入 ÷ 本期广告花费；本工具箱用此定义，来源若含其他营销费用先调整。不能解释为广告因果回报 |
| CPA / CAC | 前者按明确转化事件计算，后者按新客户计算；注明新客识别和花费范围 |
| 转化率 | 对应事件人数或订单数 ÷ 明确定义的访问/客户基数；跨系统分母先校对 |
| 复购率 | 明确首购批次、观察窗口、分母和再次购买定义；不能由全部订单中新老单占比直接替代 |
| 退款 | 区分本期退款金额、本期订单的退款和退款订单率；跨期退款会影响解读 |
| 库存覆盖 | 可售库存 ÷ 所选窗口日均需求；缺货期销量可能低估需求，无销量时不可精确估计 |

## 复盘常见判断

- 收入涨而贡献跌：检查折扣、组合、获客、履约、退款和成本覆盖；别直接归因广告。
- 点击涨而订单未涨：先核对数据与时间，再看访问质量、报价、缺货与购买阻碍；不能只凭点击断定素材有效。
- 复购看似上涨：区分客户变多、观察窗口变长和同一批客户表现改善。
- 商品卖得快：同时看贡献、缺货、在途与交期，不直接等同值得加预算。
- 没有成本：可交付销售和推广分析；贡献、盈利 CPA 与净利润明确留空或标为未知。

例如平台 A 归因收入 1200、平台 B 归因收入 800，订单系统真实收入 1500，不能写实际收入 2000。两平台归因重叠、时间与定义均可能造成差异；保留各自视图并核对。
